# Bundled fonts

The outline faces the DWG and DXF renderer substitutes for a drawing's
TrueType styles (see `crates/exav-render/src/formats/dwg/DESIGN.md`, 5.3).
Every face here is under the SIL Open Font License 1.1, whose text is in
`OFL-1.1.txt` (`OFL-arimo.txt` is Arimo's copy). Copyright and version are as
each font file declares them in its own name table. The two Arimo files are
renamed from `Arimo[wght].woff2` and `Arimo-Italic[wght].woff2`, so their
names need no escaping in a URL.
