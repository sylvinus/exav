import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

exav reads ClamAV's signature databases, answers the `clamd` and ICAP protocols
and prints `clamscan`'s output format. Its flags are its own: a `clamscan` flag
exav lacks stops the run rather than being ignored (see the
[flag matrix](/reference/clamav-flag-matrix/)).

<CardGrid>
  <Card title="Memory-safe Rust engine" icon="rocket">
    The scanning and extraction code is safe Rust (`#![forbid(unsafe_code)]` in
    the core crates). The default build links no C and generates no code at run
    time, so the memory-corruption bugs behind most scanner CVEs cannot occur in
    the code that parses hostile input.
  </Card>
  <Card title="Bounded memory" icon="bars">
    Most archives are walked member by member instead of being extracted whole,
    and a stream waits in a temp file under
    [budgets you set](/reference/cli/#buffering-a-stream-spill). A file over a
    bound is reported, not called clean.
  </Card>
  <Card title="Native YARA engine" icon="puzzle">
    Near-full YARA support through a native tree-walking evaluator: no code
    generation at scan time, a pure-Rust dependency tree, on by default.
  </Card>
  <Card title="Drop-in compatible" icon="random">
    Loads existing `.cvd`/`.ndb`/`.ldb`/`.hdb`/YARA signature databases and
    answers the `clamd` and ICAP protocols, so `clamdscan`, milters, proxies and
    existing tooling talk to exav unchanged.
  </Card>
  <Card title="Prebuilt `.exavdb`" icon="download">
    Compile a large signature set once, then load it quickly and with far less
    memory everywhere.
  </Card>
  <Card title="WASM sandbox" icon="seti:wasm">
    The whole engine compiles to a WASI module, so **untrusted** signatures can
    be loaded without host access, with no custom host code.
  </Card>
  <Card title="Never a silent clean" icon="approve-check">
    A file is reported clean only if it was fully scanned. Anything that stops a
    scan early gets a verdict of its own, which a deployment may choose to
    deliver anyway, but only by saying so.
  </Card>
  <Card title="MIT licensed" icon="open-book">
    A permissive license, with nothing derived from GPL sources.
  </Card>
</CardGrid>

:::note[Status: beta]
exav is young. It is tested differentially against ClamAV on a large corpus and
fuzzed, but a scanner earns trust from use, and it has not had much yet. Please
[report anything that looks wrong](https://github.com/sylvinus/exav/issues).
:::
