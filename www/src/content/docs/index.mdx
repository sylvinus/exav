exav is a set of tools for files you did not write and should not trust: an
attachment, an upload, a download. They are built on the same parsers,
written in safe Rust, and each bounds the work a hostile file can cause.
Each tool is usable on its own.

<CardGrid>
  <Card title="Malware scanning" icon="magnifier">
    A ClamAV-compatible scanner, daemon and ICAP server that never reports a
    file clean unless it fully scanned it.

    ```sh
    cargo install exav
    ```

    [Start here](/scanner/getting-started/introduction/) or read the
    [comparison with ClamAV](/scanner/reference/comparison-with-clamav/)
  </Card>
  <Card title="Archive extraction" icon="download">
    Bounded, memory-safe extraction of archives, disk images and documents, as
    a command, a Rust crate, and `@exav/unpack-wasm` for browsers and Node.

    ```sh
    cargo install exav-unpack
    ```

    [Start here](/unpack/)
  </Card>
  <Card title="File viewer" icon="document">
    `@exav/viewer` shows PDF, images, DWG and DXF, Office documents, IFC and
    STL models, media and archives in the browser, and can open each file in
    a sandboxed frame of its own.

    ```sh
    npm install @exav/viewer
    ```

    [Start here](/viewer/) or [try the demo](/viewer/demo/)
  </Card>
</CardGrid>

:::note[Status: beta]
exav is young. It is tested differentially against ClamAV on a large corpus and
fuzzed, but a scanner earns trust from use, and it has not had much yet. Please
[report anything that looks wrong](https://github.com/sylvinus/exav/issues).
:::
